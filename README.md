О проекте
api_yatube — это REST API для социальной сети Yatube, реализованное на Django и Django REST Framework. Проект предоставляет программный интерфейс для работы с постами, группами и комментариями, включая создание, чтение, обновление и удаление контента.

API спроектировано с учётом масштабируемости: вся логика API вынесена в отдельное приложение api, что упрощает поддержку и расширение проекта при добавлении новых приложений.

Функционал
Аутентификация по токену: доступ к API возможен только после получения токена через специальный эндпоинт.
Контроль прав доступа:
Аутентифицированный пользователь может изменять и удалять только свой контент.
Попытка изменения чужого контента возвращает ответ с кодом 403 Forbidden.
Для остальных операций (чтение) доступ предоставляется всем аутентифицированным пользователям.
Работа с ресурсами:
посты (создание, просмотр, редактирование, удаление);
группы (просмотр списка и деталей группы);
комментарии (просмотр, создание, редактирование, удаление).
Требования
Python 3.12+;
Django 5.1.1+;
Django REST Framework;
стандартные зависимости, указанные в requirements.txt.

Установка и запуск
Создайте и активируйте виртуальное окружение:

bash
python3.12 -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows
Установите зависимости:

bash
pip install -r requirements.txt
Примените миграции:

bash
python manage.py migrate
Создайте суперпользователя (для доступа к админке):

bash
python manage.py createsuperuser
Запустите сервер:

bash
python manage.py runserver
Структура проекта
posts — приложение с моделями (Post, Group, Comment и др.).
api — приложение, содержащее всю логику API (вьюсеты, сериализаторы, URL-маршруты, настройки аутентификации).
Вынесение API в отдельное приложение позволяет сохранять чистоту архитектуры и упрощает работу над большими проектами с множеством приложений.

Доступные эндпоинты
Аутентификация
POST /api/v1/api-token-auth/ — получить токен. В теле запроса передаются username и password. В ответе возвращается token.
Посты
GET /api/v1/posts/ — список всех постов.
POST /api/v1/posts/ — создать новый пост.
GET /api/v1/posts/{post_id}/ — получить пост по ID.
PUT /api/v1/posts/{post_id}/ — полностью обновить пост.
PATCH /api/v1/posts/{post_id}/ — частично обновить пост.
DELETE /api/v1/posts/{post_id}/ — удалить пост.
Группы
GET /api/v1/groups/ — список всех групп.
GET /api/v1/groups/{group_id}/ — информация о группе по ID.
Комментарии
GET /api/v1/posts/{post_id}/comments/ — список комментариев к посту.
POST /api/v1/posts/{post_id}/comments/ — добавить комментарий к посту.
GET /api/v1/posts/{post_id}/comments/{comment_id}/ — получить комментарий.
PUT /api/v1/posts/{post_id}/comments/{comment_id}/ — полностью обновить комментарий.
PATCH /api/v1/posts/{post_id}/comments/{comment_id}/ — частично обновить комментарий.
DELETE /api/v1/posts/{post_id}/comments/{comment_id}/ — удалить комментарий.
Во всех запросах, кроме получения токена, требуется передавать заголовок Authorization: Token <ваш_токен>.

Технические особенности реализации
Для работы с моделью Post используется ModelViewSet.
При необходимости ModelViewSet может применяться и для других моделей.
На все запросы POST, PUT и PATCH API возвращает объект, который был добавлен или изменён.
Используется механизм TokenAuthentication из Django REST Framework.
Локальное подключение и тестирование
Для локальной разработки и тестирования API используйте адрес: http://127.0.0.1:8000/. Все эндпоинты API доступны по префиксу /api/v1/.
